## 📧 EMAIL WORKFLOW DETAILS

### REGISTRATION EMAIL FLOW
```
1. User enters email in Register.jsx
2. Frontend validates email format (validators.js)
3. authService.register() sends email to backend
4. authController.register() validates email uniqueness
5. authService.createUser() stores email in customers table
6. Success response includes user data with email
```

### LOGIN EMAIL FLOW
```
1. User enters email in Login.jsx
2. Frontend validates email format
3. authService.login() sends credentials to backend
4. authController.login() calls findUserForLogin()
5. authService searches customers/employees by email
6. Password verification and session creation
7. JWT token includes email in payload
```

### PASSWORD RESET EMAIL FLOW
```
1. User enters email in ForgotPassword.jsx
2. authService.forgotPassword() sends email to backend
3. authController.forgotPassword() generates 6-digit OTP
4. OTP stored with email in password_resets table
5. OTP printed to terminal (dev mode)
6. User enters OTP for verification
7. authService.updatePassword() resets password for email
```

## 🚀 EMAIL INTEGRATION POINTS

### DATABASE TABLES WITH EMAIL
```sql
-- Customers Table
CREATE TABLE customers (
  customer_id SERIAL PRIMARY KEY,
  full_name VARCHAR(255) NOT NULL,
  email VARCHAR(255) UNIQUE NOT NULL,  -- EMAIL FIELD
  password VARCHAR(255) NOT NULL,
  tel VARCHAR(20),
  address TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Employees Table  
CREATE TABLE employees (
  employee_id SERIAL PRIMARY KEY,
  full_name VARCHAR(255) NOT NULL,
  email VARCHAR(255) UNIQUE NOT NULL,  -- EMAIL FIELD
  password VARCHAR(255) NOT NULL,
  nic VARCHAR(20) UNIQUE,
  telephone VARCHAR(20),
  role VARCHAR(20) CHECK (role IN ('ADMIN', 'INVENTORY', 'SALES')),
  status VARCHAR(10) DEFAULT 'ACTIVE',
  created_at TIMESTAMP DEFAULT NOW()
);

-- Password Reset Table
CREATE TABLE password_resets (
  reset_id SERIAL PRIMARY KEY,
  email VARCHAR(255) NOT NULL,  -- EMAIL FIELD
  otp VARCHAR(6) NOT NULL,
  created_at TIMESTAMP DEFAULT NOW(),
  expires_at TIMESTAMP NOT NULL
);
```

## 🔍 EMAIL DEBUGGING POINTS

### Common Email Issues
1. **Duplicate Email Error**: Check uniqueness constraints in database
2. **Email Format Error**: Verify regex validation on frontend/backend
3. **OTP Not Working**: Check password_resets table and expiration times
4. **Login Failed**: Verify email exists in customers or employees table
5. **Role Issues**: Check role mapping between database and frontend

### Email Testing Commands
```sql
-- Check duplicate emails
SELECT email, COUNT(*) FROM customers GROUP BY email HAVING COUNT(*) > 1;
SELECT email, COUNT(*) FROM employees GROUP BY email HAVING COUNT(*) > 1;

-- Check password resets
SELECT * FROM password_resets WHERE email = 'user@example.com';

-- Clear expired OTPs
DELETE FROM password_resets WHERE expires_at < NOW();
```

This authentication system provides a robust, email-centric user management solution with comprehensive security features and clear separation between customer and employee access levels.
