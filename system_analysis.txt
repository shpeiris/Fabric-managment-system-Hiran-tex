Fabric Management System - Full System Analysis

1. Overview
The Fabric Management System is a full-stack web application designed for a fabric store or warehouse. It handles both an internal administration/management side (for staff) and an external-facing side (for customers). 

The application is built using a React/Vite frontend and a Node.js/Express backend, interacting with a PostgreSQL database.

---------------------------------------------------------
ACTORS AND FEATURES
---------------------------------------------------------

Actor 1: SYSTEM ADMINISTRATOR
Access Level: ADMIN
Key Features:
- User Management: Can view, create, edit, and delete employee profiles.
- Role Assignment: Assign roles (INVENTORY, SALES) to employees.
- Security Logs Overview: View activity logs (IP, user agents) for security-sensitive actions.
- Full Dashboard Access: Aggregate statistics of total sales, total orders, available stock, and staff status.
- Global Settings/Metadata management.

Actor 2: INVENTORY MANAGER
Access Level: INVENTORY
Key Features:
- Fabric Management: Create, Read, Update, and Delete (CRUD) fabric records.
- Catalog Control: Toggle fabrics in or out of the public-facing catalog via the `is_in_catalog` parameter.
- Restock Alerts: Configure and receive alerts when `stock_quantity` drops below `reorder_level`.
- Supplier Management: Add or update records of fabric manufacturers/distributors.
- Stock Arrivals: Record incoming inventory from suppliers (`stock_arrivals`), updating the warehouse overall quantities.

Actor 3: SALESPERSON
Access Level: SALES
Key Features:
- Order Management: View customer orders, update order status (PENDING, PROCESSING, DELIVERED, CANCELLED).
- Verification: Verify orders directly with customers and update delivery information (`verified_at`, `verification_notes`).
- Payment Verification: Review payment proofs (like bank slips) and update payment status (PENDING, COMPLETED, FAILED).
- Customer Assistance: View customer details and assist with offline/in-store order placements.

Actor 4: CUSTOMER
Access Level: Customer (Authenticated via Frontend Shop)
Key Features:
- Catalog Browsing: View available fabrics sorted by price, color, or material type.
- Shopping Cart: Add items (`fabrics`) to a cart, adjust quantities (meters), and prepare for checkout.
- Checkout & Orders: Convert cart into an order, specify delivery details (address, method).
- Payments: Process payments (Bank Slip upload support).
- Order History: Review past orders, check the status of current orders.
- Reviews and Feedback: Submit structured feedback (Overall rating, Delivery, Fabric Quality) for completed orders.
- Profile Management: Update personal information and handle password resets using OTP.

Actor 5: SYSTEM (Automated Processes)
Key Features:
- Email/SMS Notifications: Sending confirmations to users via `confirmation_logs`.
- Stock Calculation: Automatically deduct `stock_available_quantity` when an order is placed.
- Token Lifecycle: Managing temporary OTP tokens and JWT for authentication.

---------------------------------------------------------
TECHNICAL MODULES & ARCHITECTURE
---------------------------------------------------------
- Authentication: Handles JWT-based logins for staff and customers, and secure OTP resets.
- Inventory: Handles the core CRUD of products and supplier restocks.
- Sales/Order: Handles checkout flow, order verification, and status transitions.
- Finance: Tracks payments, bank slip verifications, and order totals.
- Frontend: State-managed React views cleanly structured into specific module Dashboards (Sales, Inventory, Admin) using a single clean `pages/` directory architecture.
